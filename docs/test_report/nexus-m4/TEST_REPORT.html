1. 里程碑概述

M4 补齐真实产物 + 真实计量：token 用量落 usage_records + cost 推导(model_pricing) + 用量聚合 API + execpolicy 动态下发(prefix_rule 语法) + 多租户并发上限 + Web 用量看板。

关键修复：M3 generate_rules() 的 forbid()/allow() 语法未经验证且与 app-server parser 不符， M4 改用 M0 T0-4 验证的 prefix_rule(pattern=[...], decision=...) 语法，glob pattern 翻译为 argv 前缀 token 列表。

Case 4 — 多租户并发 429

tenants.max_concurrent_turns=1（default）
turn1: POST /v1/threads/{A}/turns {input:"long running"} &   (running, 持 mutex)
turn2: POST /v1/threads/{B}/turns {input:"second concurrent"}  (同租户第二 turn)
  → HTTP 429 body=too_many_concurrent_turns: limit=1   ← turn_start 前置门控

判定：同租户第二并发 turn 被 429 拒绝 PASS

门控在锁 mutex 前执行（DB count running turns），不进 driver；单 driver 串行保证真实并发 ≤1，门控语义=防积压。
