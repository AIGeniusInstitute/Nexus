1. 执行摘要

M1（身份+骨架）7 个任务全量编码完成，端到端验证通过。14 个测试用例全部 PASS，覆盖迁移幂等、JWT 登录、401/404 边界、Threads CRUD、Turns/Items、幂等缓存、令牌桶限流（12×429）、WebSocket 三态（401 无 token / 403 跨租户 / 撤销断连+item frame）、CLI 四子命令、Web 门户构建+三屏截图。

核心结论：M1 身份域 + 会话五原语骨架 + 双网关（REST/WS）+ 门户 + CLI 全部达到验收标准。有意简化 3 项（OIDC→JWT、audit 不分区、permission_snapshot NULL）符合 Simplicity First，不偏离架构产物。下一步 M2 单租户 MVP（runtime 池经 model_gateway 代理真实模型、Thread 所有权、Fork-Rollback）。

9. 关键决策与简化

  • sqlx 复用 workspace 0.9.0（非独立 0.8）：避免 libsqlite3-sys 双版本 links 冲突（codex-state 用 0.37，sqlx 0.9 也用 0.37 共存）
  • 手动迁移 include_str! + raw_sql：避免 sqlx::migrate! 宏拉 sqlite 后端 feature
  • 去掉 tower-governor 自建限流：Simplicity First，IP/user 同 DB 令牌桶模式，减少外部依赖不确定性
  • turns start 写 mock system item：真实执行留 M2 runtime 池经 model_gateway 代理
  • OIDC 简化为 JWT（HS256）：M1 用 LocalProvider，OidcProvider+Keycloak 留 M5
  • audit_logs M1 普通表：M8 改分区表
  • permission_snapshot_hash M1 NULL：M3 Fork-Rollback 填充
