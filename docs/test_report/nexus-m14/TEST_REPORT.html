6. 关键决策

6.1 fork 用单一 imported turn（不逐 turn 复制）

新 thread 一个 completed turn 携带全部历史 item（content_ref 保留）。避免逐 turn 复制的 turn id 映射复杂度（Simplicity First）。fork 线程获得完整上下文，可直接接续实验。

6.2 fork 用 INSERT...SELECT + ROW_NUMBER() 重编 seq

items UNIQUE(thread_id,turn_id,seq)：fork 复制时新 thread+新 turn_id，ROW_NUMBER() OVER (ORDER BY id) 从 1 重编，不冲突。

6.3 rollback 删 items 再删 turns（FK 顺序）

items FK turns(turn_id)，必须先删 items（WHERE turn_id > snap）再删 turns（WHERE id > snap）。事务内执行。

6.4 不冻结 snapshot 副本 + app_server_events 不删

fork/rollback 时从 live thread 读 ≤ turn_id（MVP 接受快照后线程继续写入的时序）。rollback 只恢复 thread 状态（items/turns），不擦 app_server_events 审计 trail。
