四、安全（AC7.4）

高危 amendment rm -rf 被拒绝 
POST /v1/approvals/{id}/resolve
  body: {"decision":"approve_with_amendment","amendment_command":["rm","-rf"]}
→ {"status":"approved_with_amendment"}（ticket 状态变了）
→ driver emit execpolicy/amendment
→ policy::merge_amendment: risk_of("rm -rf")=="high" → return None（拒绝写入）
→ GET rules: rm -rf* deny seed  /  rm* deny seed  （均无 amendment allow 覆盖）✓
seed deny 不被 amendment 降级（UPSERT WHERE source!='seed'） 
即使 risk=low 的 amendment 命中已有 seed 行（如 rm*），
ON CONFLICT ... WHERE policies.source != 'seed' 不满足 → 0 rows affected → 跳过。
seed deny 永远优先于 amendment allow（priority 80/100 > 40）。✓
