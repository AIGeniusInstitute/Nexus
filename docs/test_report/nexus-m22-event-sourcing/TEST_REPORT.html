AC22.1 事件落库 — golden_set publish → domain_events seq=1 publishedPASS▶

golden_set publish v1.0.0 时调用 record_event，在 domain_events 表落 seq=1, entity_type='golden_set', event_type='published' 行。

-- DB 证据
SELECT seq, entity_type, entity_id, event_type FROM domain_events;
 seq | entity_type | entity_id | event_type
-----+-------------+-----------+----------
   1 | golden_set  |         1 | published

-- curl 触发
curl -s -X POST http://localhost:8765/v1/evals/golden-sets -H "Authorization: Bearer $JWT" \
  -d '{"name":"gs-m22","cases":[...]}'
# → publish
curl -s -X POST http://localhost:8765/v1/evals/golden-sets/1/publish -H "Authorization: Bearer $JWT" \
  -d '{"version":"1.0.0"}'
# domain_events seq=1 published
AC22.2 domain_events WORM — DELETE → "append-only (WORM): modification forbidden"PASS▶

PG trigger prevent_domain_events_modification BEFORE UPDATE OR DELETE 强制不可变。

docker exec nexus-postgres psql -U nexus -d nexus -c \
  "DELETE FROM domain_events WHERE seq=1;"
-- ERROR: append-only (WORM): modification forbidden
-- CONTEXT: PL/pgSQL function prevent_domain_events_modification()

docker exec nexus-postgres psql -U nexus -d nexus -c \
  "UPDATE domain_events SET event_type='tampered' WHERE seq=1;"
-- ERROR: append-only (WORM): modification forbidden

AC22.7 CAS 写入去重 — content_hash=efbd92... 两次写同内容 hash 一致PASS▶

Content-Addressable Storage：SHA-256 内容寻址，相同内容只存一份。

curl -s -X POST http://localhost:8765/v1/cas/store -H "Authorization: Bearer $JWT" \
  -d '{"content":"hello-nexus-m22"}' | jq .
{ "ref": "cas:efbd92...", "hash": "efbd92...", "stored": true }

# 第二次写相同内容
curl -s -X POST http://localhost:8765/v1/cas/store -H "Authorization: Bearer $JWT" \
  -d '{"content":"hello-nexus-m22"}' | jq .
{ "ref": "cas:efbd92...", "hash": "efbd92...", "stored": false }
// hash 一致 ✓ stored=false（去重命中，不重复写入）

3. bug 修复记录

Bug 1: domain_events.rs anyhow! 宏需 anyhow::anyhow!

crate 级别未宏导入，anyhow!("...") 编译报错。修复：改用 anyhow::anyhow!("...") 显式路径。

Bug 2: esign hash to_rfc3339 时间精度不一致

PG TIMESTAMPTZ 微秒精度 vs chrono to_rfc3339 纳秒精度，导致 hash 不一致。修复：改用 timestamp() 秒级 i64 参与哈希，双方对齐。

Bug 3: CREATE TRIGGER 非幂等

重跑迁移报 "trigger already exists"。修复：每个 CREATE TRIGGER 前加 DROP TRIGGER IF EXISTS ... ON <table>，幂等可重入。

Bug 4: Web Table 组件用 cols/rows props 非 children

Web Table 组件 <Table cols={[...]} rows={[...]} /> 不接受 children。修复：改用原生 <table> 元素渲染 lineage/eval 数据。
