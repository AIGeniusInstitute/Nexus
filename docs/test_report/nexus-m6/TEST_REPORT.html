四、零回归（AC6.5）

4.1 安全单调：approve 不回退 deny（AC6.4）

npm install* 已是 deny(learned)。跑 1 次 approve turn → learn 对 (deny, approve) 返回 None（deny 不回退）：

after approve: npm install* → dec=deny src=learned  ← deny 永不回退 ✓

4.4 M5 并发零回归（2 turn 同时 park）

并发 2 turn → concurrent pending = 2（M4 全局 mutex 下不可能）：
  aid=19 turn=18   aid=18 turn=19
slot A: deny aid=19   → turn 18 completed
slot B: interrupt turn=19 → turn 19 interrupted
两 slot 各自 drain + 路由终结，无串扰 ✓
