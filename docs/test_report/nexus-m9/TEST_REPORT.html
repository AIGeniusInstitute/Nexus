T9-1 + T9-2 gateway 转换层验证（直连）

发 Responses 请求（扁平 tools）到 gateway，看返回 SSE 是否含 function_call item：

# 扁平 tools 格式（codex 发的）
curl -N -X POST "$GW/v1/responses" -H "Authorization: Bearer $GT" -d '{
  "model":"deepseek-v4-pro",
  "input":[{"type":"message","role":"user","content":[
    {"type":"input_text","text":"What is the weather in Beijing? Use the get_weather tool."}]}],
  "tools":[{"type":"function","name":"get_weather","description":"Get weather",
    "parameters":{"type":"object","properties":{"city":{"type":"string"}},"required":["city"]}}],
  "tool_choice":"auto","stream":true
}'

# 返回 SSE（关键事件）：
event: response.created
event: response.output_item.added  # message, output_index 0
event: response.reasoning_text.delta  # ×16 (deepseek 思考)
event: response.output_item.done     # message (empty content)
event: response.output_item.added    # ★function_call, output_index 1, in_progress
data: {"item":{"arguments":"","call_id":"call_f104cdbfd0b84b6b84e628b2",
  "id":"fc_nexus_...","name":"get_weather","status":"in_progress","type":"function_call"}}
event: response.output_item.done     # ★完整 function_call
data: {"item":{"arguments":"{\"city\": \"Beijing\"}","call_id":"call_f104...",
  "id":"fc_nexus_...","name":"get_weather","type":"function_call"},"output_index":1}
event: response.completed
data: {..."output":[{message},{function_call}],"usage":{"input_tokens":304,"output_tokens":74,"total_tokens":378}}

证明：扁平→嵌套 tools 转换成功（dashscope 返回 tool_calls）+ tool_calls 分片累积成完整 function_call item（arguments=`{"city": "Beijing"}` 字符串，call_id 正确）+ 真实 usage。
