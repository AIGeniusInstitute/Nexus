3. Bug 修复记录

3.1 EvalBatchRunRow 缺 judge_version_id 字段

现象：INSERT 写入 eval_batch_runs.judge_version_id 但 API 返回 None。

根因：EvalBatchRunRow struct 未定义 judge_version_id 字段，get_run / list_runs 的 SELECT 未取该列。

修复：struct 加字段 + get_run / list_runs SELECT 补列。

// eval_center.rs — struct 加字段 pub struct EvalBatchRunRow { // ... 既有字段 pub judge_version_id: Option, // ← 新增 } // get_run / list_runs — SELECT 补列 "SELECT id, ..., judge_version_id, aggregate FROM eval_batch_runs WHERE id=$1"

3.2 docker-compose.yml 缺 NEXUS_SIMULATE_JUDGE env

现象：容器内 judge_score 走真实 dashscope 路径失败（网络/配额问题）。

根因：docker-compose.yml 未声明 NEXUS_SIMULATE_JUDGE env，容器进程无此变量。

修复：compose 加 env + .env 设 SIMULATE_JUDGE=1。

# docker-compose.yml nexus: environment: - NEXUS_SIMULATE_APPROVAL=1 - NEXUS_SIMULATE_JUDGE=1 # ← 新增 - NEXUS_POOL_SIZE=4
