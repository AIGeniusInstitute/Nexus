6. 关键决策

6.1 权限过滤先于召回（roadmap T11-3 验收标准）

WHERE tenant_id=$X 在 ORDER BY embedding <=> $vec 之前。pgvector 0.8.x HNSW 支持过滤 ANN。跨租户文档即使 embedding 相同也不可见（AC13.5 实证）。

6.2 ACL 随索引写入 + 冗余 tenant_id

kb_documents.tenant_id 在摄入时写入（不召回时 JOIN knowledge_bases→workspaces）。冗余避免 ANN 时 JOIN（性能 + 简单）。KB 是 tenant-scoped（即使 admin 也只看本租户，数据隔离不同于 audit 跨租户管理可见性）。

6.3 手动 vec_literal 不引 sqlx-pgvector

构造 '[0.1,0.2,...]'::vector 字符串 bind，避免给 workspace 加 sqlx-pgvector feature（Surgical，避免连锁依赖变更）。

6.4 混合召回最小实现（rerank 留扩展）

向量 ANN（HNSW 余弦）+ 可选 keyword ILIKE（title OR content）。score = 1 - cosine_distance。rerank 模型需额外 API 调用，speculative，M13 用向量距离排序足够 MVP。

6.5 embedding 复用 M8 env（不新增凭证）

NEXUS_UPSTREAM_MODEL_URL / NEXUS_MODEL_KEY（M8 已用）+ NEXUS_EMBED_MODEL(default text-embedding-v3)。key 仅从 env，绝不硬编码/日志/记忆。

6.6 坑：keyword 初版只过滤 content

doc3 title="K8s 云部署" 但 content 用 "Kubernetes"→搜 "K8s" 空。改进为 title ILIKE OR content ILIKE。
