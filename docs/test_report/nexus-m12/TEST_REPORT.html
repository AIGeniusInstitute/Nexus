6. 关键决策

6.1 eval 不自动起 turn（接收 turn_id 断言）

起 turn 用既有 /v1/threads/{id}/turns（M2），eval 只接收已完成的 turn_id 断言。职责分离，避免复刻 turn_start 的 driver drain/park 逻辑（Simplicity First）。CI 脚本串联两者。

6.2 断言 status + contains（骨架可扩展）

核心断言：turn.status == expected_status + 可选 expected_contains ∈ items.content_ref。五评测平面（roadmap T8-1 全集）留扩展：case.category 字段供分类，detail JSONB 供附加指标。

6.3 run_eval tenant 隔离

查 turn 时 JOIN threads th ON th.id=t.thread_id WHERE th.tenant_id=$2，跨租户 turn 不可断言（actual_status="not_found" → passed=false）。

6.4 坑：SIMULATE_APPROVAL=1 下 turn park 阻塞

CI gate 初版用 SIMULATE_APPROVAL=1 → turn_start 审批 park 不完成（curl hang）。修复：CI gate 跑 SIMULATE_APPROVAL=0（mock 纯文本 turn 无命令→approval_policy=untrusted 不触发审批→直接 completed）。
